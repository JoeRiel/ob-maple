# ob-maple.el

This package contains Org Babel [^1] functions for Maple [^2]
evaluation. It requires the maplev package [^3]. Here is a simple
[demo](demo.org).

[^1]: <https://orgmode.org/worg/org-contrib/babel/index.html>

[^2]: <https://maplesoft.com/>

[^3]: <https://github.com/JoeRiel/maplev/>
